# 🚀 CareerPilot AI

AI-powered Resume Analyzer and Career Guidance System using Python and Streamlit.

## ✨ Features
- Resume PDF Upload
- ATS Score Analysis
- Skill Detection
- Missing Skill Suggestions
- Career Recommendations
- AIML Project Suggestions
- Interview Question Generator
- Interactive Streamlit UI

## 🛠️ Technologies Used
- Python
- Streamlit
- PyPDF2
- NLP-based Skill Matching

## 📂 Project Structure

CareerPilot-AI/
│
├── app.py
├── requirements.txt
├── README.md

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📸 Output
Upload your resume PDF and get:
- ATS Score
- Skill Analysis
- Missing Skills
- Career Recommendations
- Interview Questions
